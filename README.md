# Troop 134 Static Website

This is a static HTML/CSS/JavaScript site designed from the Troop 134 Website Starter Spec.

## Open locally
Double-click `index.html` or open it in a browser. No server, database, login, WordPress, or Wix is required.

## Update site content
Edit only `data/site.js` for events, leaders, links, documents, Eagle rows, albums, and stats.

## Folder structure
- `index.html`, `about.html`, `join.html`, `events.html`, `contact.html`
- recommended pages plus `oath-law.html`
- `css/styles.css`
- `js/site.js`
- `data/site.js`
- `images/logo/`
- `images/albums/`
